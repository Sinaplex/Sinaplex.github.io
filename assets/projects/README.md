# Portfolio project covers

These local WebP cover images are used by the project cards in `index.html`:

- `patrol-enemy.webp` — Patrol Enemy, 2D Unity project
- `maze-adventure.webp` — Maze Adventure concept
- `online-arena.webp` — 3D online game concept

Replace an image with a project screenshot or cover using the same filename to update the site without changing its HTML. Keep the image at a 16:9 aspect ratio for the card layout.
