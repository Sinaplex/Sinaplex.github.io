# Sina Plex — portfolio

پورتفولیوی فارسی و راست‌چین Sina Plex؛ ساخته‌شده با HTML و **Tailwind CSS از طریق CDN** و بدون نیاز به مرحله‌ی build.

## ساختار

- `index.html` — صفحه‌ی اصلی، استایل‌ها و تعامل‌های سایت
- `assets/projects/` — کاورهای تصویری پروژه‌ها که در بخش نمونه‌کار نمایش داده می‌شوند

برای تعویض کاور یا توضیحات هر نمونه‌کار، فایل تصویر داخل `assets/projects/` و کارت متناظر در بخش `#projects` فایل `index.html` را ویرایش کنید. ایمیل، GitHub، YouTube و Telegram نیز در همان فایل قابل تغییر هستند.
